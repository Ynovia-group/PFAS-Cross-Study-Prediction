How should I assign data roles?

update: measured soils used for calibration and, optionally, method selection.

audit: separate measured soils used only to test the selected procedure.

predict: soils without measured values that need predictions.

Keep all records from the same soil in one role. Without a role column, all measured records are used for calibration and cannot also serve as an independent test.

Match columns and scales

What does this tool assess?

Does calibration reduce error? Which soils improve or worsen? Is soil ranking still incorrect?

The tool evaluates existing predictions. To compare models or input sets, upload predictions generated using the same data partitions.

Decision rules and evidence
  1. Zero or one calibration soil: retain the reference predictions.
  2. Two or more: calibrate the reference model by default, then test on separate soils.
  3. Three or more: internal-validation selection is available for exploration; the replay did not establish an advantage.
  4. Exclude affine fits with nonpositive slopes to avoid reversing or collapsing soil order.

These counts determine which calculations are available. They do not guarantee accuracy. See the README for scope and evidence.

Interpretation and next steps
Downloads retain original predictions, the selected procedure, adjusted values, and data roles. Fitted values for calibration soils do not establish calibration effectiveness.
